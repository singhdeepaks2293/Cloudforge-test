## Top 10 gaps
1. No service fully matches AWS.
2. EC2 long tail missing: 13/27 nav items, 5 more label-only.
3. 17 exam services have no console at all — generic Home/Operations/Learning only (Aurora, Backup, Macie, Audit Manager, Artifact, CloudFront*, EFS, FSx, Shield, Control Tower, Identity Center, RAM, Direct Connect, Global Accelerator, MGN, Compute Optimizer, Savings Plans).
4. Budgets and Network ACLs land on the wrong page (/services/budgets and /services/nacl render generic ServiceDetail, though the real tables exist in Cost Explorer / VPC console).
5. AWS detail tabs were almost never observed, so CloudForge detail tabs are unvalidated (EC2 9, Lambda 6, S3 5, IAM policy detail JSON-only vs AWS 4 tabs).
6. List columns unverified for most services; DataSync is the one clear column mismatch.
7. S3 second half absent: Files, Access Grants, Analyzer, Storage Lens, Storage management.
8. VPC missing newer sections: Verified Access, Cloud WAN, PrivateLink and Lattice, DNS Firewall.
9. Restricted services (GuardDuty, Security Hub, Organizations, DMS) layouts follow public docs, not the survey.
10. No wizard steps are survey-verified for any service.

## What the survey-reconciliation test proves
Column alignment it asserts (S3, IAM Roles, Lambda, ELB, Cost Explorer/Budgets, Transit Gateway, EBS, VPN, VPC VPN/TGW). It does NOT prove tab coverage or detail tabs, and does not cover the 17 generic services or Budgets/NACLs routing.
